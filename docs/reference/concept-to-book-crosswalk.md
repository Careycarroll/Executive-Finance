## Machine-Readable Version

The crosswalk is duplicated in `concepts/registry.json` as the `sources`
array on each entry. This document is the human-readable view; the registry
is what the validator and router consume.

If the two diverge, **the registry wins.** Update this doc from the registry,
not the other way around.
