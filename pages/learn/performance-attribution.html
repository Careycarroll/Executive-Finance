The Brinson-Fachler Attribution Decomposition

1. Asset Allocation Effect ∑i(wp,i−wb,i)⋅(Rb,i−RB)\sum_{i} (w_{p,i} - w_{b,i}) \cdot (R_{b,i} - R_B)∑i​(wp,i​−wb,i​)⋅(Rb,i​−RB​) Value added by overweighting sectors whose benchmark return beat the overall total benchmark (Rb,i>RBR_{b,i} > R_BRb,i​>RB​), or underweighting lagging sectors.

3. Interaction Effect ∑i(wp,i−wb,i)⋅(Rp,i−Rb,i)\sum_{i} (w_{p,i} - w_{b,i}) \cdot (R_{p,i} - R_{b,i})∑i​(wp,i​−wb,i​)⋅(Rp,i​−Rb,i​) Cross-product effect: positive when the manager both overweights a sector and picks outperforming stocks within that same sector (often folded into Selection in institutional reporting). 
Worked Two-Sector Attribution Example (Total Benchmark Return R_B = 10.0%)
┌────────────────────────────────────────────────────────┐
│ Technology Sector:                                     │
│ • Benchmark Weight = 30%, Benchmark Return = 18.0%     │
│ • Portfolio Weight = 45%, Portfolio Return = 22.0%     │
├────────────────────────────────────────────────────────┤
│ 1. Allocation Effect:                                  │
│    (45% - 30%) × (18.0% - 10.0%) = +15% × +8% = +1.20% │
│ 2. Selection Effect:                                   │
│    30% × (22.0% - 18.0%) = 30% × +4.0% = +1.20%        │
│ 3. Interaction Effect:                                 │
│    (45% - 30%) × (22.0% - 18.0%) = +15% × +4% = +0.60% │
│ → Total Value Added from Tech = +3.00% (+300 bps)      │
└────────────────────────────────────────────────────────┘
⚠️ Common Misconceptions
  • Misconception 1: "Brinson-Hood-Beebower (BHB) and Brinson-Fachler (BF) give the same sector allocation numbers."
    Reality: In the older BHB formula, sector allocation is measured as (wp,i−wb,i)×Rb,i(w_{p,i} - w_{b,i}) \times R_{b,i}(wp,i​−wb,i​)×Rb,i​. Under BHB, overweighting a sector that returned +5%+5\%+5% when the overall market returned +15%+15\%+15% looks like a "positive +5%+5\%+5% allocation contribution," even though overweighting that lagging sector dragged down relative performance! Brinson-Fachler fixes this by subtracting overall RBR_BRB​: (wp,i−wb,i)×(Rb,i−RB)(w_{p,i} - w_{b,i}) \times (R_{b,i} - R_B)(wp,i​−wb,i​)×(Rb,i​−RB​), properly showing that overweighting a sector that underperformed the overall market is a negative allocation decision.
  • Misconception 2: "The famous Brinson study proved that 90% of returns come from asset allocation, so security selection doesn't matter."
    Reality: Brinson et al. showed that ~90% of the time-series variance of a pension fund's quarterly total return is explained by its policy benchmark asset allocation. Among active managers with similar benchmarks, cross-sectional differences in excess return are frequently driven by security selection and factor tilts.
  • Misconception 3: "Single-period arithmetic attribution sums cleanly across multiple years."
    Reality: Because portfolio returns compound multiplicatively over time, single-period arithmetic attribution effects do not sum cleanly across multi-year horizons without geometric smoothing adjustments (e.g., Carino or Menchero linking algorithms).
